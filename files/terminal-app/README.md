# Terminal.app profile: Rose Pine Moon

Palette matching WezTerm's built-in `rose-pine-moon` scheme, adapted
for macOS's built-in Terminal.app. Use this if you've dropped WezTerm
as the primary emulator and are running herdr (or tmux, or a plain
shell) directly inside Terminal.app.

## Install

Double-click `RosePineMoon.terminal` in Finder, or:

```sh
open files/terminal-app/RosePineMoon.terminal
```

Terminal.app opens a new window using the profile and adds
**Rose Pine Moon** to Terminal → Settings → Profiles.

## Make it the default

Terminal → Settings → Profiles → select **Rose Pine Moon** →
click **Default** (bottom-left). New windows will use it. Existing
windows keep their previous profile until you switch them via
Shell → Use Settings.

## Regenerating the profile

`RosePineMoon.terminal` is generated by `build_profile.py`. To
regenerate (e.g., after tweaking the palette):

```sh
/usr/bin/python3 files/terminal-app/build_profile.py
cp /tmp/rose-pine-terminal/RosePineMoon.terminal files/terminal-app/
```

Uses only the stdlib `plistlib` — no PyObjC dependency. NSColor blobs
are hand-constructed as NSKeyedArchiver format (the format Terminal.app
actually stores). See the script comments for the layout.

## Palette

Rose Pine Moon values from
<https://rosepinetheme.com/palette/ingredients/>.

| ANSI | Role     | Hex     | Rose-Pine name |
|-----:|----------|---------|----------------|
| 0    | black    | #393552 | overlay        |
| 1    | red      | #eb6f92 | love           |
| 2    | green    | #3e8fb0 | pine (teal)    |
| 3    | yellow   | #f6c177 | gold           |
| 4    | blue     | #9ccfd8 | foam           |
| 5    | magenta  | #c4a7e7 | iris           |
| 6    | cyan     | #ea9a97 | rose           |
| 7    | white    | #e0def4 | text           |
|      | bg       | #232136 | base           |
|      | fg       | #e0def4 | text           |
|      | cursor   | #56526e | highlight_high |
|      | selection| #44415a | highlight_med  |

Rose-pine has no true green, so ANSI slot 2 renders as teal (`pine`) —
this matches WezTerm's own rose-pine-moon rendering. Bright variants
(8..15) reuse the same hues; bright-black uses `muted` (#6e6a86) for
dim/comment rendering.

## Uninstall

Terminal → Settings → Profiles → select **Rose Pine Moon** → click
the minus button. Or re-import from the `.terminal` file to update in
place.

## Why not AppleScript?

Terminal.app's AppleScript API exposes only 3 color properties on a
settings set (`background`, `cursor`, `normal text`). The 16 ANSI
colors, bold text color, and selection color are not scriptable —
they can only be set through the plist. Hence the plist-generator
approach.
